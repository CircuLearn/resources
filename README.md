# 📚 Clan Learning Resources

A curated collection of domain-wise resources, guides, and references to help members upskill and grow.

---

## 🔍 Domains

- `web-dev/` → HTML, CSS, JavaScript, frameworks
- `ai-ml/` → Python, ML basics, model deployment
- `devops/` → Docker, GitHub Actions, CI/CD
- `git-github/` → Version control, PRs, workflows

---

## 📘 How to Contribute

1. Choose your domain folder
2. Add your learning resource (link, article, or repo)
3. Open a Pull Request with a short description
